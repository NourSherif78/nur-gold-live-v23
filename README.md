# Nur Jewellery - Live Gold & Currency Dashboard

منصة أسعار الذهب والسبائك اللحظية المعتمدة - مجوهرات نور (Nur Jewellery)

## التشغيل السريع
- **محلياً (Local):** اضغط مرتين على `start.bat` أو شغل `npm install` ثم `npm start`.
- **على السيرفر (Render / Cloud):**
  - **Build Command:** `npm install`
  - **Start Command:** `npm start`
